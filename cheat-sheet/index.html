How to enter a code

  1. Beat Jason and Lucia's main story. Cheats do nothing before that.
  2. Open the menu, press R1/RB to the Progress tab, and find Cheats. Most codes also need a challenge (listed below).
  3. In free-roam, press Up on the D-pad to pull out your phone.
  4. Hold L1+R1 (Xbox: LB+RB) and press the code on the D-pad. Same code on both consoles.

Save first. Turning on a cheat shuts off saving and trophies/achievements for that session.
